TODO 캘린더 프로젝트 개발 체크리스트
===========================================

사용 방법
---------

- 기본 분담은 프론트 백 을 각자가 담당하는 방식이다.
- [ ]를 [x]로 바꾸면서 진행 상황을 표시한다.
- 각 단계의 공동 확인을 완료한 후 다음 단계로 이동한다.
- API 주소, 요청/응답 형식, 날짜 기준을 변경하면 반드시 상대 팀원에게 공유한다.
- 기존 인증 기능은 필요한 경우를 제외하고 수정하지 않는다.
